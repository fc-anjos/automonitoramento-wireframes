# Wireframe 2 · Automonitoramento

Protótipo gestor em registro Balsamiq, separado do conjunto anterior.

Direção:

- entrada por visão operacional de uso/interferência;
- workbook/tabela como modo primário de navegação;
- território fixo como UGRHI-07, com sub-bacias como recorte geográfico;
- outorgados como recurso de topo;
- cadeia canônica do legado: Outorgado/Usuário -> Uso/Interferência -> Portaria/Ato -> Medidor -> Declaração;
- Uso/Interferência como registro central do automonitoramento, com Portaria/Ato espelhado do SOE;
- tela inicial como índice de usos monitorados, com inspetor lateral e registro redimensionável;
- tabs primárias usando um padrão único: índice, inspetor, registro redimensionável e workspace;
- telas em padrão console: filtros, tabela densa, ficha lateral, ações do gestor e auditoria;
- gráficos apenas como controle operacional ou evidência do registro.

```bash
npm install
npm run dev
```
